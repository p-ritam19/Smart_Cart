# SmartCart Customer Segmentation

## Overview
SmartCart Customer Segmentation is a machine learning project that analyzes customer purchasing behavior and identifies distinct customer groups using unsupervised learning techniques.

The project uses customer data stored in CSV format to perform data preprocessing, feature engineering, exploratory data analysis, dimensionality reduction and clustering.

## Objectives
- Understand customer purchasing behavior.
- Identify customer segments based on spending and demographic characteristics.
- Apply unsupervised machine learning algorithms.
- Analyze and visualize customer clusters.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- PCA
- K-Means Clustering
- Agglomerative Clustering

## Project Workflow
1. Data collection and exploration
2. Data preprocessing
3. Feature engineering
4. Outlier handling
5. Categorical encoding
6. Feature scaling
7. Dimensionality reduction using PCA
8. Optimal cluster selection
9. Customer clustering
10. Cluster characterization

## Algorithms
- K-Means Clustering
- Agglomerative Clustering
- Principal Component Analysis (PCA)

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd SmartCart-Customer-Segmentation

pip install -r requirements.txt
```

## Run the Project

Open the notebook:

```bash
jupyter notebook notebooks/smartcart.ipynb
```

Ensure the dataset is available in the expected data directory.

The project explores customer groups using clustering visualizations and analyzes their income and spending patterns.
